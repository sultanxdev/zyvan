# Projects API

Projects serve as top-level containers for environments, tenants, destinations, and billing.

---

## 1. Create a Project

<EndpointBadge method="POST" path="/v1/projects" auth="Bearer Master Key" />

<ParamGroup>
  <ParamField name="name" type="string" required location="body">
    A human-readable name for the project (e.g. `Production SaaS`).
  </ParamField>
  <ParamField name="plan" type="string" location="body" defaultValue="pro">
    The tier plan for the project: `free`, `pro`, `enterprise`.
  </ParamField>
</ParamGroup>

### Request Example

<CodeBlock language="bash" filename="create-project.sh">
curl -X POST "https://api.zyvan.dev/v1/projects" \
  -H "Authorization: Bearer zyvan_admin_key" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Production App",
    "plan": "enterprise"
  }'
</CodeBlock>
