# Python SDK

The `zyvan` Python package offers full type hinting, asynchronous (`asyncio`) support, and signature verification utilities.

---

## Installation

```bash
pip install zyvan
```

---

## Quick Example

```python
from zyvan import ZyvanClient

client = ZyvanClient(
    api_key="zyvan_live_sec_10982347",
    project_id="proj_live_99"
)

event = client.events.send(
    type="subscription.renewed",
    idempotency_key="sub_renew_9812",
    payload={"plan": "pro", "price_cents": 4900}
)

print(f"Sent event ID: {event.id}")
```
