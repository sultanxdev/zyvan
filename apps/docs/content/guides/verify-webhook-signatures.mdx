# Verify Webhook Signatures

To ensure incoming webhook requests genuinely originate from Zyvan and have not been altered or intercepted in transit, your receiver application must cryptographically verify the request's HMAC-SHA256 signature.

Zyvan signs every outbound webhook using the destination's unique secret key (`whsec_...`).

---

## The Signature Header Specification

With each delivery attempt, Zyvan transmits:

| Header | Example | Description |
| :--- | :--- | :--- |
| `x-zyvan-timestamp` | `1774353600` | Unix epoch time in seconds when the request was dispatched. |
| `x-zyvan-signature` | `v1=99f2e718b5c90a12e34f8a...` | Hex-encoded HMAC-SHA256 signature computed over `${timestamp}.${rawBody}`. |

Zyvan also supports the combined format in `x-zyvan-signature`:
```http
x-zyvan-signature: t=1774353600,v1=99f2e718b5c90a12e34f8a7b6c5d4e3f...
```

---

## 3 Rules of Webhook Verification

<Steps>
  <Step number={1} title="Always Use Raw Unparsed Bytes">
    The signature is computed over the exact byte stream sent across the wire. Never parse the body as JSON and re-stringify it before verifying. Re-stringifying changes object key ordering and whitespace, which permanently breaks the signature hash.
  </Step>

  <Step number={2} title="Mitigate Replay Attacks with Timestamp Windows">
    Verify that the `x-zyvan-timestamp` is within a reasonable tolerance window (recommended: **300 seconds / 5 minutes**) relative to your server's current time:
    $$
    | \text{CurrentTime} - \text{Timestamp} | \le 300\text{s}
    $$
  </Step>

  <Step number={3} title="Use Constant-Time String Comparison">
    Standard string equality operators (`===` or `==`) terminate early on the first differing byte, leaking timing information that enables side-channel attacks. Always use constant-time comparison methods (e.g. `crypto.timingSafeEqual` in Node.js, `hmac.compare_digest` in Python, or `subtle.ConstantTimeCompare` in Go).
  </Step>
</Steps>

import hashlib
import time
from fastapi import FastAPI, Request, HTTPException, status

app = FastAPI()
SECRET = "whsec_99f2e718b5c90a12e34f8a..."

@app.post("/api/webhooks")
async def handle_webhook(request: Request):
    # 1. Read raw bytes
    raw_body = await request.body()
    sig_header = request.headers.get("x-zyvan-signature", "")
    ts_header = request.headers.get("x-zyvan-timestamp", "")

    if not sig_header or not ts_header:
        raise HTTPException(status_code=401, detail="Missing signature headers")

    # 2. Check 5-minute replay window tolerance
    try:
        ts = int(ts_header)
    except ValueError:
        raise HTTPException(status_code=400, detail="Invalid timestamp format")

    if abs(time.time() - ts) > 300:
        raise HTTPException(status_code=400, detail="Timestamp out of tolerance window")

    # 3. Compute HMAC-SHA256 over f"{timestamp}.{raw_body}"
    payload_to_sign = f"{ts}.".encode("utf-8") + raw_body
    computed_hash = hmac.new(
        SECRET.encode("utf-8"),
        payload_to_sign,
        hashlib.sha256
    ).hexdigest()
    expected_signature = f"v1={computed_hash}"

    # 4. Constant-time comparison
    if not hmac.compare_digest(sig_header, expected_signature):
        raise HTTPException(status_code=401, detail="Invalid webhook signature")

    return {"received": True}`

import (
	"crypto/hmac"
	"crypto/sha256"
	"crypto/subtle"
	"encoding/hex"
	"fmt"
	"io"
	"math"
	"net/http"
	"os"
	"strconv"
	"time"
)

func webhookHandler(w http.ResponseWriter, r *http.Request) {
	secret := os.Getenv("ZYVAN_WEBHOOK_SECRET")

	// 1. Read raw body
	bodyBytes, err := io.ReadAll(r.Body)
	if err != nil {
		http.Error(w, "Cannot read body", http.StatusBadRequest)
		return
	}

	sigHeader := r.Header.Get("x-zyvan-signature")
	tsHeader := r.Header.Get("x-zyvan-timestamp")
	if sigHeader == "" || tsHeader == "" {
		http.Error(w, "Missing signature headers", http.StatusUnauthorized)
		return
	}

	// 2. Validate timestamp tolerance (5 minutes)
	ts, err := strconv.ParseInt(tsHeader, 10, 64)
	if err != nil || math.Abs(float64(time.Now().Unix()-ts)) > 300 {
		http.Error(w, "Timestamp out of range", http.StatusBadRequest)
		return
	}

	// 3. Compute HMAC-SHA256
	mac := hmac.New(sha256.New, []byte(secret))
	mac.Write([]byte(fmt.Sprintf("%s.", tsHeader)))
	mac.Write(bodyBytes)
	expectedSig := "v1=" + hex.EncodeToString(mac.Sum(nil))

	// 4. Constant-time comparison
	if subtle.ConstantTimeCompare([]byte(sigHeader), []byte(expectedSig)) != 1 {
		http.Error(w, "Invalid signature", http.StatusUnauthorized)
		return
	}

	w.WriteHeader(http.StatusOK)
	w.Write([]byte("{\"received\":true}"))
}`

require 'rack'

def verify_zyvan_webhook(raw_body, signature_header, timestamp_header, secret)
  return false if signature_header.nil? || timestamp_header.nil?

  # Check 5-minute replay window
  ts = timestamp_header.to_i
  return false if (Time.now.to_i - ts).abs > 300

  # Compute HMAC-SHA256
  signed_payload = "#{timestamp_header}.#{raw_body}"
  digest = OpenSSL::Digest.new('sha256')
  expected_sig = "v1=" + OpenSSL::HMAC.hexdigest(digest, secret, signed_payload)

  # Constant-time comparison
  Rack::Utils.secure_compare(signature_header, expected_sig)
end`

## Zero-Downtime Secret Rotation

When rotating your signing secret in the Zyvan dashboard, you can accept both the new and previous secrets simultaneously during migration without dropping a single event:

```typescript
import { webhooks } from '@zyvan/sdk';

const event = webhooks.constructEvent({
  payload: rawBody,
  signature,
  timestamp,
  // Pass an array: candidate signatures are tested against all keys
  secret: [
    process.env.ZYVAN_NEW_WEBHOOK_SECRET!,
    process.env.ZYVAN_OLD_WEBHOOK_SECRET!,
  ],
});
```
