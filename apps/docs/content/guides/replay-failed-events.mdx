# Replay Failed Events from DLQ

When a webhook destination experiences an extended outage and exhausts all configured retries, Zyvan marks the delivery as `DEAD_LETTER` and moves it to the **Dead Letter Queue (DLQ)**.

Once you or your customer resolves the downstream issue, you can replay the delivery with **1 click or an API call**.

---

## Zero-Overwrite Guarantee

<Callout type="tip" title="Audit Trail Preservation">
  Replaying a failed delivery **never overwrites or clears past failed attempts**. Zyvan creates a new execution branch while preserving the complete historical trace of every previous failure for auditing and compliance.
</Callout>

## Bulk Replay (Disaster Recovery)

If an entire destination was down for hours, you can trigger a bulk replay across all failed deliveries:

```bash
curl -X POST "https://api.zyvan.dev/v1/projects/proj_live_99/dlq/bulk-replay" \
  -H "Authorization: Bearer zyvan_live_sec_10982347" \
  -H "Content-Type: application/json" \
  -d '{
    "destination_id": "dest_acme_corp_01",
    "failed_after": "2026-09-08T00:00:00Z"
  }'
```
