# Destinations API

Destinations specify target webhook URLs, their HMAC signing secrets, and individual retry parameters.

---

## 1. Create a Destination

<EndpointBadge method="POST" path="/v1/projects/:projectId/destinations" auth="Bearer API Key" />

<ParamGroup>
  <ParamField name="tenant_id" type="string" required location="body">
    The ID of the tenant owning this destination.
  </ParamField>
  <ParamField name="url" type="string" required location="body">
    The receiver URL (`https://...`).
  </ParamField>
  <ParamField name="secret" type="string" location="body">
    Custom signing secret. If omitted, Zyvan auto-generates a secure 32-byte secret.
  </ParamField>
  <ParamField name="rate_limit" type="number" location="body" defaultValue="100">
    Max requests per second for this destination.
  </ParamField>
</ParamGroup>

### Request Example

```bash
curl -X POST "https://api.zyvan.dev/v1/projects/proj_live_99/destinations" \
  -H "Authorization: Bearer zyvan_live_sec_10982347" \
  -H "Content-Type: application/json" \
  -d '{
    "tenant_id": "tenant_acme_corp",
    "url": "https://acme.com/api/webhooks",
    "rate_limit": 100
  }'
```
