# Deliveries API

A **Delivery** is the unit of work representing the routing of an event to a single destination. The Deliveries API allows inspecting delivery statuses, latency metrics, and detailed HTTP attempt execution logs.

---

## 1. List Deliveries by Destination

<EndpointBadge method="GET" path="/v1/destinations/:destinationId/deliveries" auth="Bearer API Key (events:read)" />

Retrieve paginated delivery jobs for a specific destination.

### Query Parameters

| Parameter | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `limit` | `integer` | `50` | Maximum items to return (1 – 100). |
| `cursor` | `string` | — | Opaque pagination cursor. |

### cURL Example

```bash
curl -X GET "https://api.zyvan.dev/v1/destinations/dst_01H8X92M4Q01/deliveries?limit=25" \
  -H "Authorization: Bearer zyv_live_99f2e718b..."
```

### Response (`200 OK`)

```json
{
  "data": [
    {
      "id": "del_01H8X92M4Q892",
      "eventId": "evt_01H8X92M4Q",
      "destinationId": "dst_01H8X92M4Q01",
      "status": "DELIVERED",
      "attemptsCount": 1,
      "lastStatusCode": 200,
      "createdAt": "2026-03-24T12:00:00Z",
      "deliveredAt": "2026-03-24T12:00:00.412Z"
    }
  ],
  "pagination": {
    "hasMore": false,
    "nextCursor": null
  }
}
```

## 3. Replay a Delivery

<EndpointBadge method="POST" path="/v1/deliveries/:id/replay" auth="Bearer API Key (delivery:replay)" />

Reset a failed or dead-lettered delivery back to `PENDING` state to be immediately picked up by an active delivery worker.

### cURL Example

```bash
curl -X POST https://api.zyvan.dev/v1/deliveries/del_01H8X92M4Q892/replay \
  -H "Authorization: Bearer zyv_live_99f2e718b..."
```

### Response (`200 OK`)

```json
{
  "id": "del_01H8X92M4Q892",
  "status": "PENDING",
  "message": "Delivery successfully queued for replay."
}
```
